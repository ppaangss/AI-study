# AI-study

매일 AI에게 배운 것을 저장·추적하는 공부 위키.

세션에서 공부한 원본은 `_raw/`에 그대로 쌓이고, 개념 단위 세부 정리는 `index/`에 모인다. 저녁에 index를 보며 복습하고 블로그(AI 극복하기 카테고리)에 직접 타이핑한다.

- `_raw/` — 세션 공부 원본 (날짜별 폴더, 불변)
- `index/` — 개념 단위 세부 정리 (공부·블로그 작성 재료)
- `daily/` — 날짜별 공부 기록
- `topics/` — 주제별 이력 인덱스 (`/sync`가 자동 생성, 링크만)
